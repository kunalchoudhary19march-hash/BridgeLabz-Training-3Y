Assignment 1 - Q2: Diagram & Explanation of Client-Server Model

The client-server model works as follows: the client (browser or app) sends an HTTP request to the server for a resource (a web page, image, or data). The server receives the request, processes it (sometimes fetching data from a database), and sends back an HTTP response, usually as HTML, JSON, or a file. The client then renders this response for the user to view.

Basic Flow:
Client → Request (HTTP) → Server → Processing → Response (HTML/JSON) → Client (renders page).
