Assignment 1 - Q5: What is a Web Server? Examples

A web server is software (often running on dedicated hardware) that stores, processes, and delivers web pages to clients over the internet using the HTTP/HTTPS protocol. It listens for incoming requests from browsers, retrieves or generates the requested content, and sends it back as a response.

Common Web Servers:

  • Apache HTTP Server: Open-source, highly customizable, widely used.
  • Nginx: High performance, asynchronous, popular for reverse proxying & static serving.
  • Microsoft IIS: Built for Windows Server environments.
  • LiteSpeed: Lightweight and high performance web server.
