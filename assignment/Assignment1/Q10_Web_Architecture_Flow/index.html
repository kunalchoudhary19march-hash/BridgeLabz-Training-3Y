Assignment 1 - Q10: Basic Web Architecture Flow

The basic web architecture flow involves four main components: the Client sends a request to the Server; the Server processes the request and may call an API for specific functionality or communicate with a Database to fetch/store data; the Database returns the requested data to the Server; and finally, the Server sends the response back to the Client, which renders and displays it to the user.

Flow: Client → (HTTP Request) → Server → (Query) → Database → (Data) → Server → (via API, if needed) → Server → (HTTP Response) → Client.
