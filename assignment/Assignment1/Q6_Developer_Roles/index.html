Assignment 1 - Q6: Roles in Web Development

Frontend Developer

Designs and builds the user interface and user experience of the website using HTML, CSS, and JavaScript; ensures the site is responsive, accessible, and visually appealing.

Backend Developer

Builds the server-side logic, APIs, and application workflows; connects the frontend to the database and handles authentication, security, and data processing.

Database Administrator (DBA)

Designs, manages, and maintains the database; ensures data integrity, performs backups, optimizes queries, and manages access permissions and security.
