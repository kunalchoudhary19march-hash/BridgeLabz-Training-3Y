Assignment 1 - Q7: Install and Configure VS Code

  1. Download VS Code from code.visualstudio.com for your operating system and install it.
  2. Open VS Code and go to the Extensions panel (Ctrl+Shift+X).
  3. Install helpful extensions such as Live Server (for auto-reloading HTML pages), Prettier (code formatter), and HTML CSS Support / JavaScript (ES6) code snippets.
  4. Create a project folder with index.html, style.css, and script.js files.
  5. Right-click index.html and select 'Open with Live Server' to preview the page in your browser.
