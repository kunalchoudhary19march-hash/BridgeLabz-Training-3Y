Assignment 1 - Q4: Tools Required to Set Up a Web Development Environment

  • Code Editor / IDE (e.g., VS Code): Used to write and edit HTML, CSS, and JavaScript code with features like syntax highlighting and extensions.
  • Web Browser (e.g., Chrome, Firefox): Used to run and preview the website, and to debug it using built-in Developer Tools.
  • Version Control System (e.g., Git): Used to track changes in code and collaborate with a team without overwriting each other's work.
  • Node.js and npm: Provide a JavaScript runtime outside the browser and a package manager to install libraries/frameworks.
  • Web Server (Local, e.g., XAMPP/Live Server extension): Used to test dynamic pages and simulate a real hosting environment locally.
  • Database Software (e.g., MySQL, MongoDB): Used to store and manage application data.
  • Terminal/Command Line: Used to run commands, install packages, and manage the project through Git and npm.
