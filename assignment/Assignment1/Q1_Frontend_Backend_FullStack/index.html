Assignment 1 - Q1: Difference between Frontend, Backend, and Full-Stack Development

Frontend Development

Frontend development deals with everything a user sees and interacts with directly in the browser — layout, design, buttons, forms, and animations. It is built using HTML, CSS, and JavaScript, along with frameworks like React or Angular. For example, the visual product listing page and shopping cart interface on Amazon is frontend work.

Backend Development

Backend development handles the server side of an application — business logic, database operations, authentication, and APIs. It runs on the server and is invisible to the user. Languages like Node.js, Python (Django/Flask), Java, or PHP are commonly used. For example, when Amazon processes a payment or checks stock in its database, that is backend work.

Full-Stack Development

Full-stack development refers to working on both the frontend and backend of an application. A full-stack developer can design the user interface as well as build the server logic and database that power it. For example, a developer who builds both the UI of a food-delivery app and the backend that tracks orders and restaurants is a full-stack developer.
