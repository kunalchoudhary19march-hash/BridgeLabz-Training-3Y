Assignment 1 - Q8: Static vs Dynamic Websites

Static Websites

A static website displays the same fixed content to every visitor. It is built using only HTML and CSS, does not interact with a database, and the content changes only when a developer manually edits the code. For example, a simple portfolio or brochure website with fixed pages is static.

Dynamic Websites

A dynamic website generates content on the fly based on user interaction, data from a database, or server-side logic, so different users may see different content. It uses server-side languages (like PHP, Node.js, Python) along with a database. For example, an e-commerce site like Amazon or a social media site like Instagram is dynamic.
