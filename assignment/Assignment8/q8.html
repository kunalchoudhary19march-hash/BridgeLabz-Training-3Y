Box-Sizing Comparison

Default (content-box)

Width 250px is only the content. Padding (30px x 2) and border (5px x 2) are added on top.

Total width = 250 + 60 + 10 = 320px

box-sizing: border-box

Width 250px already includes the padding and border, so the content shrinks to fit.

Total width = 250px

Why it matters

With border-box, the width you set is the width you get. This makes layouts much easier to calculate and is why most developers apply it to every element.
