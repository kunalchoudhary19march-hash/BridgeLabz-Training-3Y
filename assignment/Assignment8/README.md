## 🛠 Features Covered
- **Pseudo-Classes**: `:hover`, `:focus`, `:active`, `:nth-child(even)`
- **Tooltips**: Pure CSS tooltips with pseudo-elements (`::after`) and smooth fade-in transitions.
- **Image Showcase**: Grid layout, scale hover effects, semi-transparent overlays, and responsive design.
- **CSS Selectors**: Element, class, ID, attribute (`a[href^="https"]`), descendant, child, adjacent sibling, and general sibling selectors.
- **Button Collection**: Primary, secondary, outline, disabled, and interactive hover/active states.
- **CSS Animations**: Custom `@keyframes` animations (`slide`, `bounce`, `colours`).
- **UI Components**: Modern search bar, styled dropdown select menu, and gradient background cards.
- **Box-Sizing**: In-depth comparison of `content-box` vs `border-box`.
- **Combined Effects**: Smooth transform, scale, rotation, translation, shadow, and transition combinations.
- **Mini UI Layout**: Complete card interface with left thumbnail image, responsive flexbox layout, and styled HTML5 form inputs.
