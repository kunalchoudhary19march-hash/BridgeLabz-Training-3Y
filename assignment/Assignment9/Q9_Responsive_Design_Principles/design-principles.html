Responsive Design Principles

Fluid Layouts

Use percentages or flexible units instead of fixed pixels so layouts stretch and shrink.

.container {
  width: 90%;
  max-width: 1000px;
}

Flexible Media

Images and video scale within their container and never overflow it.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Media queries change the layout at chosen screen widths.

@media (max-width: 600px) {
  .grid { grid-template-columns: 1fr; }
}
