What is Responsive Design?

Responsive web design makes a page look good on phones, tablets and desktops. It uses fluid grids, flexible images and media queries so that the layout adapts to the size of the screen.

Cheat Sheet Preview

  • Flexbox: display: flex;
  • Grid: display: grid;
  • Media query: @media (max-width: 700px)
  • Fluid text: clamp()
